# BU Drop24 website

A responsive static storefront for BU Drop24.

## Preview locally
Open `index.html` in a browser.

## Publish
Upload the contents of this folder to GitHub Pages, Netlify, or Vercel as a static site.

## Edit
- Product photos and logo are in `assets/`.
- Product names, pricing, and copy are in `index.html`.
- Instagram links currently point to https://www.instagram.com/drop24_bu/.

This is a front-end catalogue only. Orders are sent to Instagram; it does not process payments or collect customer details.
